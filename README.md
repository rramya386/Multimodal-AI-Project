# 🧠 Multimodal Q&A Assistant

This app allows users to upload an **image** or **audio** and ask questions using natural language. It combines **OpenAI GPT-4V** for image reasoning and **Whisper** for audio transcription.

## Features
- Upload images and ask questions (e.g., "What’s happening in this photo?")
- Transcribe uploaded audio files and display the text

## Tech Stack
- OpenAI GPT-4V (Vision model)
- Whisper (speech-to-text)
- Streamlit for UI
- Pillow, Torch, OpenCV

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Environment
Add your OpenAI API key:

```bash
export OPENAI_API_KEY=your_key_here
```
